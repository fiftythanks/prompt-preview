# Prompt review

Language feedback on prompts before they reach the intended agent.

## Language

**Draft**:
The user's current wording of a prompt awaiting submission.

**Reviewer**:
The language reviewer, distinct from the target agent that receives the submitted prompt.

**Correction**:
Feedback identifying a language error or a departure from the user's house style. House-style departures are preferences, not universal language errors.

**Suggestion**:
Optional advice on wording that is not a correction.

**House style**:
The user's chosen writing conventions, distinct from generally applicable grammar and spelling rules.

**Rewrite**:
A revision of the draft authored by the user in response to review feedback, rather than wording applied by the reviewer.

**Bypass**:
The user's explicitly confirmed choice to send a draft without satisfying the review's outstanding requirements.
